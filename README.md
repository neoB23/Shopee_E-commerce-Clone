
# 🛒 Shopee Clone

**Shopee Clone** is a responsive e-commerce web application built using **React (Vite)** and **Tailwind CSS**. It replicates the core shopping experience with product listings, category browsing, cart management, and dynamic user interactions. Designed to showcase modern frontend practices, component-based architecture, and smooth performance.

---

## ✨ Features

* Browse products by categories
* View product details
* Add/remove items from the cart
* Responsive layout for mobile and desktop
* Smooth interactive UI using Tailwind CSS
* Component-based architecture for scalability

---

## 🛠 Tech Stack

* **React** – Frontend framework
* **Vite** – Development tooling and fast build system
* **Tailwind CSS** – Utility-first styling for modern UI
* Optional: State management via **useState** or **useReducer**

---

## 📦 Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/shopee-clone.git
cd shopee-clone
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start development server

```bash
npm run dev
```

The app should now be running at `http://localhost:5173`.
